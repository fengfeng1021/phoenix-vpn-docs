快速連線（推薦 D 槽免安裝）

🖥 Windows sing-box 免驅動 · D 槽

  1. 免安裝，已解壓到 D:\NekoBox\sing-box.exe（81 MB，用戶態，無需 WireGuard 驅動，不佔 C 槽）
  2. 雙擊 D:\NekoBox\start.bat 啟動，看到 mixed-in listening on 127.0.0.1:2080
  3. 雙擊 D:\NekoBox\enable-proxy.bat 一鍵設系統代理為 127.0.0.1:2080（或手動在瀏覽器設 HTTP/SOCKS5 代理）
  4. 瀏覽器開 whoer.net 確認顯示 Phoenix, US；關閉時執行 disable-proxy.bat + stop.bat
  5. 備用：原生 WireGuard 設定檔仍在 %USERPROFILE%\Desktop\wireguard-us-phoenix.conf，可用官方客戶端匯入（需驅動，已安裝在 C:\Program Files\WireGuard 但曾因驅動缺失改用 sing-box）
手動測試：Invoke-WebRequest -Proxy http://127.0.0.1:2080 https://ipinfo.io/json
應回傳 "country":"US" "city":"Phoenix"

📱 手機 / 平板

  1. App Store / Play Store 搜 WireGuard 安裝
  2. 點 + → Create from file or archive → 匯入同一個 .conf
  3. 或在電腦用 qrencode 掃 QR 匯入（部署時已產生）
  4. 開啟開關，允許 VPN 配置
同一個設定檔可在多裝置匯入，但不要同時連線同一 Peer，會互搶。需多裝置請在伺服器新增 Peer。
