快速連線

🖥 Windows 已安裝到 D 槽

  1. 安裝程式在 D:\Installers\wireguard.msi 已安裝到 C:\Program Files\WireGuard（僅 9 MB，含驅動必須在 C 槽，已備份 exe 到 D:\WireGuard\）
  2. 打開 WireGuard → 點 Add Tunnel → Import tunnel from file
  3. 選擇 %USERPROFILE%\Desktop\wireguard-us-phoenix.conf
  4. 點 Activate，狀態變綠色即連上美國
  5. 瀏覽器開 whoer.net 確認顯示 Phoenix, US
備用啟動（Portable）：
D:\WireGuard\wireguard.exe /installtunnelservice D:\WireGuard\wireguard-us-phoenix.conf

📱 手機 / 平板

  1. App Store / Play Store 搜 WireGuard 安裝
  2. 點 + → Create from file or archive → 匯入同一個 .conf
  3. 或在電腦用 qrencode 掃 QR 匯入（部署時已產生）
  4. 開啟開關，允許 VPN 配置
同一個設定檔可在多裝置匯入，但不要同時連線同一 Peer，會互搶。需多裝置請在伺服器新增 Peer。

新增第二個裝置

SSH 進主機執行：

ssh -i ~/.ssh/vpn-us-phoenix ubuntu@129.146.115.218
# 在伺服器上產生第二個客戶端
wg genkey | tee /tmp/c2_priv | wg pubkey > /tmp/c2_pub
wg genpsk > /tmp/c2_psk
cat /tmp/c2_priv
cat /tmp/c2_pub
# 然後編輯 /etc/wireguard/wg0.conf 新增一個 [Peer]，重啟 wg-quick@wg0
